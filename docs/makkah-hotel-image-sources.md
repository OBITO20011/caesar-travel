# Makkah hotel image sources

Photos in `public/hotels/makkah` show the named property. Each was taken from the
hotel's own website, then lightly edited (16:9 crop, gentle contrast/colour/sharpness,
WebP compression). Nothing in the scene was added or removed.

The travel company should confirm marketing-use permission with the hotel or its
supplier (Anjum runs a Travel Agent Portal) before reusing these photos outside
this website.
