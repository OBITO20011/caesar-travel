# Makkah hotel image sources

Photos in `public/hotels/makkah` show the named property. Each was taken from the
hotel's own website or the hotel's owner-uploaded Google listing photos (or, for the
clock tower, a freely licensed Wikimedia Commons photo), then lightly edited (16:9 crop, gentle contrast/colour/sharpness,
WebP compression). Nothing in the scene was added or removed.
